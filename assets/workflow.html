Bilibili Analyze Skill 工作流程图

从 B站链接到 Obsidian 笔记的全自动分析流水线

0

环境预检

python scripts/preflight.py
检测 yt-dlp、ffmpeg、ffprobe、Python、Chrome、Whisper 是否就绪，缺失时给出安装命令。
1

下载（可并行）

python scripts/download.py <url> --workdir <dir>
元数据 yt-dlp → metadata.json
音频 最佳音频流 → ffmpeg 转 mp3
封面 缩略图 thumbnail.jpg
CC 字幕 如有则直接下载
metadata.json audio_best.mp3 thumbnail.jpg *.srt（可选） state.json
遇到 412？ → 换 b23.tv 短链 传 cookies.txt --cookies-from-browser
2

转写

python scripts/transcribe.py <workdir/state.json>
有 CC 字幕？ → 直接解析，跳过 Whisper → faster-whisper openai-whisper 回退
transcript_full.json transcript_segments.txt transcript.txt
3

AI 分章 + HTML 生成

python scripts/build_page.py <workdir>
  • AI 按视频自然结构分章（problem / steps / pitfalls / conclusion / key_quote）
  • 为每章生成动态 SVG 图表
  • 构建单页离线 HTML，内联 CSS + SVG
chapters.json analysis.html
4

截图切片（CDP clip）

python scripts/screenshot.py <workdir>
Chrome headless 打开 analysis.html，使用 CDP Page.captureScreenshot + clip 按 <section class="chapter"> 精确截取每章内容，合并为完整长截图。
section_1.png … section_N.png screenshot_full.png sections_manifest.json
5

写入 Obsidian（可选）

python scripts/export_obsidian.py <workdir> --vault <vault>
复制附件到 vault，生成带 YAML frontmatter、章节结构、截图嵌入和跳转链接的 Markdown 笔记。
学习/视频课程/<title>.md 附件/视频课程附件/<title>-*.png
